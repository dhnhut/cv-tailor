# Evaluations

This folder will hold the evaluation benchmark for the agents: a golden dataset and the runners that score agent output against it.

The benchmark measures output quality and checks the golden rule: the agent never invents experience, skills, or any fact that is not in the candidate's own documents (`AGENTS.md` §5.1, §5.5, and SAFE-03). It runs as part of the delivery process.

The dataset, metrics, and pass thresholds are designed together with the first agent. Until then this folder is a placeholder.
